Кістки

Опис проєкту

«Кістки» — це консольний навчальний застосунок, розроблений мовою C++. Програма призначена для вивчення кісткової системи людини в інтерактивному форматі через текстовий інтерфейс.

Застосунок надає користувачу інформацію про основні типи кісток, їхню будову, функції та особливості. Навігація здійснюється за допомогою меню в консолі, що робить програму простою у використанні та не потребує додаткових графічних бібліотек.

Проєкт виконаний у межах курсової роботи з дисципліни програмування.

Функціональні можливості

Головне меню навігації
Перегляд інформації про типи кісток
Вивчення будови кістки
Ознайомлення з функціями кісткової системи
Відображення довідкової інформації
Перехід між розділами програми
Завершення роботи через пункт меню «Вихід»

Структура програми

Програма складається з декількох логічних розділів:

1. Головне меню
2. Типи кісток
3. Будова кістки
4. Функції кісткової системи
5. Додаткова інформація
6. Вихід із програми
